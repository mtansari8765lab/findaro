QR Code Generator

Turn any link or text into a downloadable QR code, instantly.

What it does

Turns any link or text into a QR code you can download as a PNG and print or share. Type a URL — a website, a menu, a Wi-Fi login page, a payment link — and the code renders as you type. It is free, with no account and no watermark, and the code is generated on your device using an open-source library.

How it works

type a URL or any text and the QR code renders as you type, using an open-source QR library loaded from a CDN. Download it as a PNG for printing or sharing. Generation happens on your device.

Try it

Type https://mtansari8765lab.github.io/findaro/ and the QR code appears instantly; download the PNG, print it on a flyer or a shop counter, and anyone who scans it opens the Findaro homepage. Test every code by scanning it with your own phone before you print a batch — a code that links to the wrong address is worse than no code at all.

What stays private

Your link or text stays on your device: the code is drawn in your browser and nothing you type is uploaded. The only network request is the open-source QR library itself, loaded from the jsDelivr CDN when the page loads.

Limitations

The QR code simply encodes the text you typed: if the address is wrong, the code faithfully points at the wrong address. Long text makes a denser, harder-to-scan code, so keep links short where you can. A printed code needs good contrast and a reasonable size — a tiny, low-contrast code on a glossy surface may not scan.

Frequently asked questions

Do the QR codes expire?

No. A QR code is just a picture of your text or link — it has no expiry date and no tracking. It stops working only if the link it points to stops working.

Is the link I type sent to a server?

No. The code is drawn on your device. The only network request is the open-source QR library itself, loaded from the jsDelivr CDN when the page loads.
